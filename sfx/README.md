# Hoormand sound-effect pack

Use these in every Hoormand reel / video.

| file | use |
|---|---|
| riser.wav | 1–2 s before a big reveal (hook headline, Hoormand screenshot, final logo) |
| whoosh.wav | scene / panel transitions |
| swoosh.wav | quick slide-ins (cards, captions entering) |
| pop.wav | each step card, icon or highlighted (yellow) keyword appearing |
| sparkle.wav | Hoormand logo, @hoormandcrm end card, "feature" moment |
| impact.wav | the hook's key word / a big number landing |
| glitch.wav | the "mistake" or problem moment, max once per video |

Mix 12–18 dB under the voice so speech stays clear; never stack more than two effects at once.
